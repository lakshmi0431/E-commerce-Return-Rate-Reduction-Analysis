<h1 align="center">📊 E-Commerce Return Rate Reduction Analysis</h1>

<h2>📌 Project Overview</h2>

<p>
This project analyzes e-commerce return data to identify the key factors influencing product returns and helps businesses reduce return rates through data-driven insights.
</p>

<p>
The project combines <b>Python</b>, <b>SQL</b>, and <b>Power BI</b> to clean data, perform exploratory data analysis (EDA), build a machine learning model for return prediction, and create an interactive dashboard.
</p>

<hr>

<h2>🎯 Objective</h2>

<ul>
<li>Analyze customer return behavior.</li>
<li>Identify products with high return rates.</li>
<li>Compare return rates across product categories.</li>
<li>Study the impact of discounts on returns.</li>
<li>Analyze payment methods and shipping methods.</li>
<li>Predict return probability using Logistic Regression.</li>
<li>Build an interactive Power BI dashboard.</li>
</ul>

<h2>📌 Key Insights</h2>

<ul>
<li>Around <b>50%</b> of orders were returned.</li>
<li>Clothing products have the highest return percentage.</li>
<li>Discounts influence customer return behaviour.</li>
<li>Different payment methods show different return rates.</li>
<li>Common return reasons include defective products, wrong items, changed mind, and products not matching descriptions.</li>
</ul>
